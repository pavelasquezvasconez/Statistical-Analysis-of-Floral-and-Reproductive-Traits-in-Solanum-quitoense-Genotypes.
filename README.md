This repository contains the dataset, R scripts, statistical analyses, and graphical outputs generated for the phenotypic evaluation of Solanum quitoense genotypes. The study includes repeated measurements of vegetative, morphological, physiological, and reproductive traits, including plant height, stem diameter, canopy diameter, number of leaves, total leaf area, leaf area index (LAI), prickle density, SPAD chlorophyll readings, floral buds, inflorescences, open flowers, and floral categories based on pistil condition. The repository includes the original dataset, reproducible R workflows for statistical modeling and multiple comparisons, analysis reports, and publication-ready figures. These resources are provided to support reproducibility, data reuse, and further comparative and meta-analytical studies of phenotypic variation in lulo (Solanum quitoense) germplasm.
